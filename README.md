# お化け横丁 (Obake Yokocho)

Хэллоуинская игра для уроков японского: улица ёкаев, пять комнат и финальное шествие 百鬼夜行.

## Файлы
- `index.html` — сама игра (всё в одном файле).
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — чтобы игру можно было установить на телефон как приложение и играть без интернета.

## Как выложить на GitHub Pages
1. Залейте все файлы из этой папки в корень репозитория (Add file → Upload files).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через пару минут игра откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

При обновлении игры достаточно заменить только `index.html`.
